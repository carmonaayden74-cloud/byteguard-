# ByteGuard

Professional Cybersecurity Tools Suite

## Quick Start

```bash
npm install
npm run dev
```

Visit <http://localhost:3000>

## Environment Setup

Copy `.env.local` from your secure location or contact admin for credentials.

Required variables:

- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_ANON_KEY
