## 🚀 Key Improvements

### 1. Performance & GPU Acceleration

- **GPU-Layered Animations**: Integrated `will-change: transform` and `translateZ(0)` into all core visual effects.
- **Scroll Stability Patch**: Fixed the "Subo y Baja" (scrolling bounce) issue by moving `.laser-line` animations from relative/absolute to `fixed` positioning, preventing document height artifacts.
- **Improved Terminal Persistence**: Refined `TerminalLog` scrolling logic to prevent full-page jumps during log updates.
- **Zero Cascading Renders**: Eliminated `setState` in `useEffect` bottlenecks.
- **Lazy State Initialization**: Refactored heavy state logic to use lazy initializers, significantly reducing the initial paint time.
